# Generative AI & Prompt Engineering Showcase

A collection of interactive educational explorations covering Generative AI, Prompt Engineering, Linguistic Intelligence, LLM prompting, and Diffusion-based Image Generation.

Each HTML file presents a different AI concept through an interactive visual experience rather than conventional static notes.

---

## Projects

### 1. `Q1_Fashion_Through_Time (2).html`
**Time Traveller – Fashion Through Time**

An interactive exploration of how prompt engineering can progressively transform a vague visual instruction into a detailed AI-generated visual narrative.  
It demonstrates six stages: basic prompting, prompt analysis, prompt rewriting, negative prompting, final composition, and reverse engineering.  
A key feature is the comparison between what was **intended** and what the AI actually generated before refining the prompt.  
This makes it a practical demonstration of **iterative visual prompt engineering and AI output analysis**.

---

### 2. `Q2_CaseLens_AI (1).html`
**CaseLens AI – AI-Assisted Crime Scene Analysis**

A conceptual educational prototype showing how Computer Vision and Generative AI could assist in organising observations from a fictional crime-scene image.  
The workflow progresses from **Scene → Vision → Evidence → Classification → Summary → Report**.  
It includes a proposed system architecture, evidence classification, AI observation matrix, and conceptual report-generation workflow.  
The project specifically demonstrates **AI-assisted analysis while keeping human investigators responsible for verification and final conclusions**.

---

### 3. `Selfstudy IV Web.html`
**Applied Prompt Engineering & Linguistic Intelligence**

An interactive research showcase combining **Prompt Unbundling, Linguistic Analysis, and Generative AI Feature Extraction**.  
It demonstrates how a compressed visual prompt can be decomposed into **12 independently controllable components** and reconstructed into an optimized prompt.  
It also analyses a paragraph through **17 linguistic features** and explores extracting a writing profile for generating style-preserved content on new topics.  
This makes the project unique as a bridge between **Prompt Engineering, Computational Linguistics, and Generative AI**.

---

### 4. `The_City_Beneath_the_City (2).html`
**The City Beneath the City – Diffusion-Based Image Generation**

An immersive archaeological-themed exploration of **Diffusion-based Image Generation**.  
It explains the conceptual generation process as **Text Prompt → Noise → Denoising → Generated Image** while using a hidden ancient civilization as the visual theme.  
The generated visuals are presented as a conceptual reconstruction rather than authentic archaeological evidence.  
The project combines **Generative AI education, diffusion concepts, and visual storytelling** into an interactive manuscript-style experience.

---

### 5. `one-world-thousand-ways-of-seeing.html`
**One World, A Thousand Ways of Seeing**

An exploration of how a diffusion-based image generator transforms a textual concept into a visual representation.  
Its central concept combines **human visible-light vision, dog colour perception, snake infrared detection, bee ultraviolet perception, and eagle visual acuity** within one environment.  
The project connects biological perception with **Computer Vision and AI-based image generation**.  
It demonstrates how a carefully structured prompt can translate a complex scientific concept into an AI-generated visual narrative.

---

### 6. `prompt-labyrinth.html`
**PROMPT//LABYRINTH – Navigating the Intelligence Behind AI Prompts**

An interactive learning environment that presents Prompt Engineering as a visual **nine-node knowledge labyrinth** rather than a conventional study document.  
It covers Role Prompting, GPT Prompting Tactics, Zero-Shot vs Few-Shot Prompting, Text Classification, LLM vs Traditional ML, Decision concepts, learning resources, and a prompt cheatsheet.  
Interactive navigation allows users to move between concepts while the interface tracks the current learning section.  
Its uniqueness lies in transforming **AI prompting concepts into an interactive educational experience**.

---

### 7. `the-four-kingdoms.html`
**The Four Kingdoms – A Comparative Study of Diffusion Models**

A comparative exploration of AI image generation using **four image-generation systems, four prompts, and sixteen generated visions**.  
The interactive experience presents the systems as four "kingdoms" and examines their generated outputs through a structured comparison.  
It explores how identical prompting can result in different interpretations, levels of fidelity, artistic treatment, and unexpected additions.  
The project demonstrates **comparative evaluation of generative image outputs rather than examining only a single AI-generated result**.
